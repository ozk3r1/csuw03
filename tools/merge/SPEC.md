# 多批次結果彙整工具規格書 (tools/merge/SPEC.md)

本文件為「我的實驗室工具箱」之子工具「多批次結果彙整」功能規格書，本工具完全遵守全域 `SPEC.md` 規範。

---

## 1. 工具目標與定位

* **工具名稱**：多批次結果彙整 (Multi-batch Results Aggregator)
* **放置路徑**：`tools/merge/`（包含獨立之 `index.html`、`calculator.js`、`ui.js`）
* **核心功能**：
  1. 支援同時上傳多份跨週/跨批次之農藥殘留檢測報表（CSV 格式）與農藥容許量標準表（`pesticide_limits.csv`）。
  2. 自動解決由不同檢測人員匯出導致的「欄位命名異構」與「農藥大小寫不一致」問題。
  3. 自動彙整產生**「樣品矩陣總表 (Wide Format)」**，並篩選出**「超過容許量超標清單」**。
  4. 支援一鍵分別匯出總表與超標清單為相容 Excel 的 CSV 檔案。

---

## 2. 資料正規化與欄位別名映射規範

### 2.1 批次日期解析
* 系統自動由上傳檔案之檔名擷取批次日期或批次代碼（例如檔名 `batch_20260920.csv` 自動解析為 `2026-09-20`）。

### 2.2 異構欄位自動映射表 (Header Aliases)
系統必須自動識別並映射不同人員命名的欄位：

| 標準化內部欄位 | 支援的來源欄位別名 (忽略大小寫與首尾空格) |
| :--- | :--- |
| **sampleId** | `Sample ID`, `SampleID`, `樣品編號`, `樣品ID`, `Sample` |
| **matrix** | `Matrix`, `基質`, `樣品類型`, `蔬果種類` |
| **analyte** | `Analyte`, `化合物`, `農藥名稱`, `項目`, `Compound` |
| **area** | `Area`, `Peak Area`, `面積`, `峰面積` |
| **isArea** | `IS Area`, `ISTD Area`, `內標面積`, `內標峰面積` |
| **calcConc** | `Calc Conc (mg/kg)`, `Conc. mg/kg`, `濃度`, `定量濃度`, `Conc` |

### 2.3 農藥名稱正規化 (Analyte Normalization)
* 比對農藥名稱時一律進行去空格與大小寫不敏感轉換（例如 `CARBOFURAN`、`Carbofuran` 與 `carbofuran` 一律視為同一農藥）。
* 顯示與匯出時採用標準駝峰式（Title Case）名稱（如 `Carbofuran`）。

## 3. 超標判定演算法與 `<LOQ` 規範

### 3.1 `<LOQ` 判定原則
* 凡數值標記為 **`<LOQ`**（或無法定量之極低訊號），一律判定為**「未檢出 / 合格」**，不在總表中標註超標，亦不列入超標清單。

### 3.2 超標判定公式
* 若樣品之檢出濃度為有效數值 $C$（單位 $\text{mg/kg}$），且該農藥於限量標準表中有定義示範容許量 $MRL$：
  * **超標 (Exceeded)**：$C > MRL$
  * **合格 (Compliant)**：$C \le MRL$
* **超標幅度計算**：
  $$\text{超標倍數} = \frac{C}{MRL} \quad (\text{四捨五入至小數點後 2 位，如：超標 1.22 倍})$$

## 4. 輸出介面與 CSV 匯出規格

### 4.1 彙整總表 (Consolidated Sample Matrix Table - Wide Format)
* **列結構**：以「單一樣品」為列（每週 6 樣品，3 週共 18 列）。
* **欄結構**：
  1. 批次日期
  2. 樣品編號
  3. 蔬菜基質
  4. ~ 8. 各農藥檢測數值欄（`Carbofuran`, `Imidacloprid`, `Acetamiprid`, `Chlorpyrifos`, `Fipronil`）
* **樣式標註**：
  * 檢出超標之數值，於儲存格內以醒目紅色徽章（Badge）標註（如 `<span class="badge-danger">0.6084 (超標)</span>`）。
  * 合格檢出以綠色數值顯示，`<LOQ` 以淺灰色顯示。

### 4.2 超標違規清單 (Exceedance List)
* **資料欄位**：
  1. 批次日期
  2. 樣品編號
  3. 蔬菜基質
  4. 超標農藥
  5. 實測濃度 ($\text{mg/kg}$)
  6. 示範容許量 ($\text{mg/kg}$)
  7. 超標幅度 / 說明
* 若當前無任何超標樣品，顯示綠色提示「🎉 所有樣品均符合農藥殘留標準」。

### 4.3 雙 CSV 匯出功能
1. 📥 **匯出彙整總表 CSV**：匯出完整的 18 樣品農藥矩陣表。
2. 🚨 **匯出超標清單 CSV**：僅匯出違規樣品之詳細明細。
* 兩者皆強制加入 **UTF-8 with BOM (`\uFEFF`)**，確保 Excel 在繁體中文 Windows 上開啟完全不亂碼。

## 5. 程式架構與品保規範

* **純計算核心 (`calculator.js`)**：
  * 獨立處理 CSV 字串解析、別名映射、矩陣 Pivot 轉換與超標邏輯判定。
  * 100% 不依賴瀏覽器 DOM，可在 Node.js 環境中獨立測試與執行。
* **畫面互動邏輯 (`ui.js`)**：
  * 支援多檔案批次拖曳上傳與容許量表上傳。
  * 負責 DOM 渲染、警示橫幅與 CSV 下載觸發。
* **一鍵範例體驗**：
  * 頁面提供顯眼「📂 載入範例資料」按鈕，非同步載入 `examples/merge/` 中的 3 週批次檔與限量檔，1 秒完成運算與呈現。
* **資安與隔離**：
  * 所有計算 100% 在瀏覽器本機內執行，絕不將農殘數據上傳任何外部伺服器。
