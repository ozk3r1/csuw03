📐 換算公式與基質規範說明

  • 水樣 (報告單位：µg/L)： $$\text{報告濃度 } (\mu\text{g/L}) = C_{\text{上機}} (\text{換算至 } \mu\text{g/L}) \times \text{稀釋倍數}$$ （水樣屬均相液態，不使用定容體積與樣品重）
  • 土壤與食品 (報告單位：mg/kg)： $$\text{報告濃度 } (\text{mg/kg}) = \frac{C_{\text{上機}} (\text{換算至 } \text{mg/L}) \times \text{稀釋倍數} \times \text{定容體積 } (\text{mL})}{\text{樣品重 } (\text{g})}$$ （固體前處理消解後定容，報告濃度以質量基準回報；若上機濃度為 $\mu\text{g/L}$ 則自動除以 1000 轉換）
  • 容錯機制：若遇數據缺失（如空值）或定容稱重不合理，系統會清晰標記並保留行數，供後續追蹤與覆核。
