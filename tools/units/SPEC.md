# 稀釋與單位換算工具規格書 (tools/units/SPEC.md)

本文件為「我的實驗室工具箱」之子工具「稀釋與單位換算」功能規格書，本工具完全遵守全域 `SPEC.md` 規範。

---

## 1. 工具目標與定位

* **工具名稱**：稀釋與單位換算 (Dilution & Unit Converter)
* **放置路徑**：`tools/units/`（包含獨立之 `index.html`、`calculator.js`、`ui.js`）
* **核心功能**：支援使用者上傳微量分析檢測結果報表（CSV 格式），自動識別樣品基質（水樣、土壤、食品），進行單位正規化、稀釋還原與前處理公式換算，輸出合規之報告濃度。
* **目標報告濃度單位**：
  * **水樣**：統一回報 $\mu\text{g/L}$。
  * **土壤與食品**：統一回報 $\text{mg/kg}$。
* **數值呈現規範**：
  * 報告濃度預設四捨五入至**小數點後 4 位**，並自動省略末尾無意義的 0（如 `62.5`、`25.5387`）。

---

## 2. 單位正規化規範 (Unit Normalization)

儀器輸出與人工登錄之單位可能混雜且大小寫不一，系統必須於換算前進行字串清洗與正規化：
1. **字串清理**：去除首尾空格 (`trim()`)，並轉為小寫 (`toLowerCase()`)，將 Unicode 微米符號 `µ` 轉換為英文字母 `u`。
2. **支援單位與換算基準**：
   * `ug/l`, `µg/l`, `ug/l` $\rightarrow$ 基準濃度 $1.0\ \mu\text{g/L}$（或 $0.001\ \text{mg/L}$）
   * `ppb` $\rightarrow$ 等同 $1.0\ \mu\text{g/L}$
   * `ng/ml` $\rightarrow$ 等同 $1.0\ \mu\text{g/L}$
   * `mg/l` $\rightarrow$ 等同 $1000.0\ \mu\text{g/L}$（或 $1.0\ \text{mg/L}$）
   * `ppm` $\rightarrow$ 等同 $1000.0\ \mu\text{g/L}$（或 $1.0\ \text{mg/L}$）

## 3. 計算公式定義 (Calculation Formulas)

### 3.1 水樣 (Water)
水樣為均相液態樣品，不需定容體積與樣品重：
$$\text{報告濃度 } (\mu\text{g/L}) = C_{\text{上機}} (\text{換算至 } \mu\text{g/L}) \times DF$$

### 3.2 土壤與食品 (Soil & Food)
固態基質樣品，經消解後定容，報告濃度以乾/濕重質量基準回報：
$$\text{報告濃度 } (\text{mg/kg}) = \frac{C_{\text{上機}} (\text{換算至 } \text{mg/L}) \times DF \times \text{定容體積 } (\text{mL})}{\text{樣品重 } (\text{g})}$$
若上機濃度以 $\mu\text{g/L}$ 表示，則公式等價為：
$$\text{報告濃度 } (\text{mg/kg}) = \frac{C_{\text{上機}} (\mu\text{g/L}) \times DF \times \text{定容體積 } (\text{mL})}{1000 \times \text{樣品重 } (\text{g})}$$

## 4. 例外處理與品保稽核匯出規範 (QA/QC & Exception Handling)

1. **完整稽核留存（100% 列對齊）**：
   * 畫面與匯出 CSV **完整保留所有樣品列**（包含缺漏數據之 `F-304`）。
   * 換算失敗的列在報告濃度留空，並在備註清楚標記原因（如：`數據缺失 (上機濃度空值)`、`定容體積異常`、`未知單位`）。
2. **樣品編號自動修剪**：
   * 樣品編號（如 `W-107 `）自動去除首尾多餘空格。
3. **固體樣品缺少定容或稱重**：
   * 若樣品重 $\le 0$ 或定容體積 $\le 0$ 或留空，標註為「前處理數值異常」。

## 5. 程式架構規範

依專案規格，計算邏輯與畫面程式嚴格分離：
* `calculator.js`：純計算模組，包含資料解析、正規化、公式換算與 4 位小數格式化，不依賴 DOM，可在 Node.js 環境獨立執行。
* `ui.js`：負責 DOM 操作、檔案拖曳上傳、結果表格繪製、警示提示與 UTF-8 BOM CSV 完整稽核匯出。
* `index.html`：獨立工具頁面，包含導航返回大廳、載入範例資料與檔案拖曳上傳區。
